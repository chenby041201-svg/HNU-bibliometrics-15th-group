4. 数据质量问题及处理建议
4.1 发现的问题
1.	DOI 字段缺失：共计 12 条文献无 DOI 标识，不利于文献精准溯源
2.	参考文献字段缺失：14 条文献缺失 CR 字段，会小幅影响共被引网络计算精度
3.	作者机构缺失：少量文献无作者单位信息，无法开展机构合作分析
4.	参考文献格式问题：部分参考文献存在作者缩写、期刊简写不统一的情况
4.2 处理建议
1.	缺失字段补充：针对无 DOI、无参考文献的文献，通过标题 + 作者组合在 WOS 平台检索补充信息；无法补充的文献做单独标记。
2.	机构信息完善：对缺失 C1 字段的文献，结合作者姓名与研究方向补充机构信息。
3.	参考文献标准化：应用清洗规则统一参考文献格式，规范作者缩写、期刊简写形式。
4.	数据二次核验：对所有文献字段进行抽样复查，保障后续网络分析结果稳定。

6. 数据处理流程
1.	数据导入: 读取 WOS 原始 CSV 数据
2.	数据清洗: 应用清洗规则 CR001-CR014，剔除关键字段为空的无效数据
3.	数据去重: 以 DOI 为唯一标识完成全局去重
4.	格式标准化: 统一作者、参考文献、关键词文本格式
5.	数据验证: 逐项核查字段完整性、格式、准确性
6.	数据导出: 输出清洗后的标准化数据至 processed 文件夹，用于后续分析
7. 质量控制措施
•	自动化检查: 使用 Python 脚本自动检测字段缺失、重复数据与格式异常
•	人工审核: 对缺失 DOI、参考文献的文献进行人工复核与信息补全
•	版本控制: 通过 Git 对原始数据、清洗后数据、清洗规则进行版本管理
•	规则迭代: 根据数据特征持续优化清洗、消歧规则，保证数据长期可用
