课堂实操练习：共被引边权重计算
1. 共被引边权重手算示例
1.1 示例数据

引用论文	被引用论文
P1	A, B, C
P2	A, B, D
P3	A, C, D
P4	B, C, D
P5	A, B, C, D
P6	A, C
P7	B, D
1.2 共被引矩阵构建
论文	A	B	C	D
A	-	4	4	3
B	4	-	3	4
C	4	3	-	3
D	3	4	3	-
详细解释：
•	A 和 B 的共被引场景：P1、P2、P5、（无其他）→ 共 4 次
￮	P1 引用 A+B，P2 引用 A+B，P5 引用 A+B，无其他论文同时引用 A+B → 总计 4 次
•	A 和 C 的共被引场景：P1、P3、P5、P6 → 共 4 次
•	A 和 D 的共被引场景：P2、P3、P5 → 共 3 次
•	B 和 C 的共被引场景：P1、P4、P5 → 共 3 次
•	B 和 D 的共被引场景：P2、P4、P5、P7 → 共 4 次
•	C 和 D 的共被引场景：P3、P4、P5 → 共 3 次
1.3 各论文被引用总次数
论文	被引用次数	引用来源
A	5	P1, P2, P3, P5, P6
B	5	P1, P2, P4, P5, P7
C	5	P1, P3, P4, P5, P6
D	5	P2, P3, P4, P5, P7
2. Cosine 相似度计算
2.1 公式回顾
Plain Text
cosine_similarity(X, Y) = 共被引次数(X,Y) / (sqrt(被引总次数(X)) * sqrt(被引总次数(Y)))
2.2 全量计算示例
论文对	共被引次数	Cosine 相似度计算	结果（保留 4 位小数）
A-B	4	4 / (sqrt(5)*sqrt(5)) = 4/5	0.8000
A-C	4	4 / (sqrt(5)*sqrt(5)) = 4/5	0.8000
A-D	3	3 / (sqrt(5)*sqrt(5)) = 3/5	0.6000
B-C	3	3 / (sqrt(5)*sqrt(5)) = 3/5	0.6000
B-D	4	4 / (sqrt(5)*sqrt(5)) = 4/5	0.8000
C-D	3	3 / (sqrt(5)*sqrt(5)) = 3/5	0.6000
2.3 计算逻辑说明
Cosine 相似度本质是将论文的被引场景视为向量，通过向量夹角衡量关联度：
•	被引总次数的平方根是向量的模长，消除了 “高被引论文天然共被引次数多” 的偏差
•	取值范围为 [0,1]，值越接近 1，两篇论文的引用分布越相似
3. Jaccard 相似度计算
3.1 公式回顾
Plain Text
jaccard_similarity(X, Y) = 共被引次数(X,Y) / (被引总次数(X) + 被引总次数(Y) - 共被引次数(X,Y))
3.2 全量计算示例
论文对	共被引次数	Jaccard 相似度计算	结果（保留 4 位小数）
A-B	4	4 / (5+5-4) = 4/6	0.6667
A-C	4	4 / (5+5-4) = 4/6	0.6667
A-D	3	3 / (5+5-3) = 3/7	0.4286
B-C	3	3 / (5+5-3) = 3/7	0.4286
B-D	4	4 / (5+5-4) = 4/6	0.6667
C-D	3	3 / (5+5-3) = 3/7	0.4286
3.3 计算逻辑说明
Jaccard 相似度聚焦 “共被引次数占总独特引用场景的比例”：
•	分母代表 “引用 X 的论文 + 引用 Y 的论文 - 同时引用 X 和 Y 的论文”，即覆盖 X 或 Y 的所有独特引用论文数
•	更适合分析 “两篇论文的共同受众占比”，而非绝对关联强度
4. 阈值选择逻辑
4.1 Top-N 阈值
应用场景	N 值选择	选中边	网络特征
核心关联分析	3	A-B、A-C、B-D	仅保留 Top3 高权重边，网络密度低，聚焦强关联
全关联分析	6	所有边	保留完整关联，网络密度高，包含弱连接
中等关联筛选	4	A-B、A-C、B-D、A-D	平衡强 / 弱连接，兼顾核心与潜在关联
4.2 Min Weight 阈值
基于原始共被引次数
阈值	选中边	筛选逻辑
4	A-B、A-C、B-D	仅保留强共被引关系
3	所有边	保留全部关联，包含中等强度
5	无	阈值过高，过滤所有连接
基于 Cosine 相似度
阈值	选中边	筛选逻辑
0.8	A-B、A-C、B-D	仅保留高相似性边
0.7	A-B、A-C、B-D	仍为高相似性边（无 0.7~0.8 区间数据）
0.6	所有边	包含中等相似性边
基于 Jaccard 相似度
阈值	选中边	筛选逻辑
0.6	A-B、A-C、B-D	保留高比例共被引边
0.5	A-B、A-C、B-D	仍为高比例边（无 0.5~0.6 区间数据）
0.4	所有边	包含低比例共被引边
4.3 阈值敏感性分析
1.	网络密度变化：
￮	阈值从 0.6（Cosine）提升至 0.8 时，网络边数从 6 降至 3，密度下降 50%
￮	阈值从 0.4（Jaccard）提升至 0.6 时，边数同样从 6 降至 3，密度下降 50%
2.	节点保留情况：
￮	阈值≥3（原始共被引次数）时，所有节点均被保留（无孤立节点）
￮	阈值 = 4 时，仍无孤立节点（核心边连接所有节点）
3.	噪声过滤效果：
￮	阈值 = 0.8（Cosine）可过滤掉 A-D、B-C、C-D 等弱连接，减少无意义关联
￮	阈值 = 0.6（Cosine）保留的弱连接（如 A-D）可能是潜在研究关联，需结合领域知识判断
5. 实操注意事项
5.1 数据预处理
1.	去重：同一篇引用论文重复引用同一被引论文时，仅计 1 次
2.	标准化：统一论文编号格式（如 A/a/ 论文 A 需归一化为 A）
3.	异常值处理：剔除被引次数为 0 的论文（无关联意义）
5.2 计算工具选择
工具	适用场景	优势
Excel	小样本手算（≤10 个被引论文）	操作简单，可视化强
Python（Pandas/Numpy）	大样本计算（≥100 个被引论文）	自动化计算，支持批量处理
Gephi	网络可视化 + 阈值筛选	直观展示网络结构变化
5.3 结果解读
1.	避免单一指标决策：结合 Cosine（绝对相似性）和 Jaccard（相对比例）综合判断
2.	结合领域知识：若 A-D 是跨学科关联，即使相似度低也可能有研究价值
3.	动态阈值调整：不同研究主题的 “强关联” 阈值不同（如前沿领域阈值可降低，经典领域可提高）
6. 结论
1.	共被引边权重核心价值：
￮	原始共被引次数反映绝对关联强度，适合小范围核心分析
￮	Cosine 相似度消除引用量级偏差，适合跨领域 / 跨量级论文比较
￮	Jaccard 相似度反映相对关联比例，适合分析 “共同受众” 特征
2.	阈值选择策略：
￮	探索性分析：选择 Top-N（N = 总边数的 50%~70%）或 Min Weight = 中位数
￮	验证性分析：选择 Top-N（N = 总边数的 30%~50%）或 Min Weight = 上四分位数
￮	精准核心分析：选择 Top-N（N≤总边数的 30%）或 Min Weight = 最大值的 80%
3.	实操建议：
￮	小样本（≤20 个被引论文）：优先手算 + Excel 验证，确保逻辑无误
￮	大样本（≥100 个被引论文）：用 Python 自动化计算，Gephi 可视化网络结构
￮	最终结论需结合领域知识，避免纯数值驱动的阈值选择
