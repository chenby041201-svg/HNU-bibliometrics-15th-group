二维过渡金属氧化物异质结文献分析产出记录
产出记录
1. 项目概述
1.1 项目背景
•	项目名称: 二维过渡金属氧化物异质结文献分析
•	数据来源: Web of Science (WOS) CSV 格式数据
•	时间范围: 2012-2025
•	数据量: 原始数据 2352 条，清洗去重后有效文献 2349 条
1.2 研究目标
•	构建二维过渡金属氧化物异质结相关文献的图数据模型
•	分析文献之间的引用关系和共被引关系
•	探索该研究领域的知识结构和发展趋势
2. 数据处理流程
2.1 数据获取
•	数据源: Web of Science 数据库
•	检索策略: 以二维过渡金属氧化物、异质结为主题检索词，时间范围 2010-2025
•	数据格式: CSV 格式
2.2 数据清洗与预处理
•	清洗规则: 应用 cleaning\[_rules.md](_rules.md) 中定义的规则
•	消歧处理: 对作者、论文和关键词进行消歧
•	数据验证: 检查数据完整性和一致性
2.3 图数据模型构建
•	节点类型: 论文、作者、关键词、期刊
•	边类型: 作者 - 论文、论文 - 关键词、论文 - 期刊、论文 - 论文引用、作者合作、关键词共现、论文共被引
•	权重计算: 基于共现次数和相似度计算
3. 决策依据
3.1 图数据模型设计
•	节点选择: 基于文献计量学常用实体类型
•	边类型选择: 基于文献之间的常见关系类型
•	权重设计: 基于学术网络分析的标准方法
3.2 相似度计算方法选择
•	Cosine 相似度: 考虑了论文的被引用频率，更适合比较不同引用量级的论文
•	Jaccard 相似度: 关注共被引次数在总引用中的比例，更适合衡量相对关联度
3.3 阈值选择策略
•	Top-N 方法: 保证网络规模可控，适合初步分析
•	Min Weight 方法: 保留所有达到一定重要性的连接，适合深入分析
3.4 数据质量控制
•	完整性检查: 确保关键字段无缺失
•	一致性检查: 确保数据格式和命名统一
•	准确性检查: 确保数据值合理有效
