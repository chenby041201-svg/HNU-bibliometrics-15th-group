基于初步的图谱和 CSV 数据透视，当前光催化领域有以下几个极具研究价值的方向（Candidates），可作为接下来的期末大作业选题或论文深入切入点：

## 候选方向一：基于 S-Scheme (S型异质结) 的光催化研究知识图谱与前沿演进
* **选题背景**: 从 `关键词共现图谱.jpg` 和 `文献耦合图谱.jpg` 中可以明显看到，`heterojunction`（异质结）是核心热点，且最新的耦合聚类高度集中在新型异质结的构造上。
* **研究内容**:
  1. 筛选出数据集中含有 "S-scheme"、"Z-scheme" 的文献。
  2. 运用代码对比传统异质结与新型异质结在年度发文上的更替趋势。
  3. 分析具体是哪些核心作者（如利用 `作者中心性分析.csv` 中的高中心性学者）在引领这个细分前沿。

## 候选方向二：第一性原理理论计算（DFT）在光催化材料领域的知识扩散研究
* **选题背景**: 在 `top50高频被引文献.csv` 中，除了材料学文献，高居前三的居然有两篇是物理学第一性原理计算的经典文献（Perdew 1996, Kresse 1996）。这说明物理计算对该领域产生了巨大的知识输入。
* **研究内容**:
  1. 以这两篇计算物理文献为“施引源”，追踪整个数据集中有哪些论文引用了它们。
  2. 分析光催化领域从何时开始大规模引入 DFT 模拟，并结合关键词看计算主要用于解决什么物理问题（如能带对齐、电荷分离机理）。

## 候选方向三：光催化研究领域的核心学者学术谱系与中国学者的影响力崛起
* **选题背景**: 从 `作者合作网络.jpg` 和 `top20作者.csv` 来看，形成了以 Tahir、余家国、许晖、李华明等为核心的紧密网络，且中国学者占据了半壁江山。
* **研究内容**:
  1. 利用 Python 对 `作者中心性分析.csv` 排序，划分出“老一代奠基人（如 1972 年的 Fujishima）”与“新一代高产中坚”。
  2. 提取机构和国家字段，做国家间的合作网络分析，定量证明中国学者在 2017-2023 爆发期中所起到的推动作用。
