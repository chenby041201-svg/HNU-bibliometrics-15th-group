本项目的数据分析主要围绕文献计量学的核心维度（时间、作者、文献、关键词）展开。以下为当前生成的数据文件及其字段定义：

## 1. 基础时序数据 (`年度发文趋势.csv`)
* **用途**: 分析光催化领域历年的发展阶段与发文热度。
* **数据格式**:
  | 字段名 | 类型 | 说明 | 示例 |
  | :--- | :--- | :--- | :--- |
  | Year (PY) | Integer | 文献发表年份 | 2012 |
  | Publication Count | Integer | 当年发文总量 | 12 |

## 2. 作者分析数据
### 2.1 高产作者看板 (`top20作者.csv`)
* **用途**: 识别该领域的头部学者与高产团队。
* **数据格式**: `[Author_Name, Document_Count]`

### 2.2 核心作者网络属性 (`作者中心性分析.csv`)
* **用途**: 评估作者在学术网络中的权力和桥梁作用。
* **数据格式**:
  | 字段名 | 类型 | 说明 |
  | :--- | :--- | :--- |
  | Author | String | 作者姓名 |
  | Betweenness Centrality | Float | 中介中心性（值越高，越处于合作桥梁位置） |
  | Eigenvector Centrality | Float | 特征向量中心性（连接了多少大牛） |

## 3. 文献引文数据 (`top50高频被引文献.csv`)
* **用途**: 挖掘本领域的知识基础与划时代奠基文献（如 1972 年 Nature 奠基文）。
* **数据格式**:
  | 字段名 | 类型 | 说明 | 示例 |
  | :--- | :--- | :--- | :--- |
  | Document | String | 文献标识 (作者, 年份, 期刊) | FUJISHIMA A, 1972, NATURE |
  | Local Citations | Integer | 在本数据集中的被引频次 | 230 |
  | Global Citations | Integer | 在整个 Web of Science 中的总被引 | 12500 |

## 4. 图谱网络映射关系 (JPG 图像说明)
以下可视化图谱基于 VOSviewer 生成，其背后的矩阵关系存储在数据缓存中：
* `关键词共现图谱.jpg`: 节点为关键词，连线表示它们在同一篇论文中出现的频次。
* `文献共被引分析.jpg`: 节点为被引文献，连线表示它们同时被后来的一篇新论文引用的频次（追溯历史基础）。
* `文献耦合图谱.jpg`: 节点为在研文献，连线表示它们引用了相同的老文献（代表当下的课题组聚类）。
* `作者合作网络.jpg`: 节点为学者，连线表示联合署名发表。
