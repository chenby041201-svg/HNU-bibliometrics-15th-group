## 2. 研究热点深度解读 (`keyword_cooccurrence.jpg`)

### 2.1 核心材料两强争霸：TiO2 与 g-C3N4
在共现图谱中，`titanium dioxide` 和 `g-C3N4 (类石墨相氮化碳)` 拥有全网最大的节点面积和最密集的连线，是无可争议的“双子星”：
* **TiO2 (二氧化钛)**：作为光催化领域的“鼻祖”，因其无毒、化学性质极稳定且成本低廉，依然是各类复合材料必选的基底之一。但其宽禁带限制了其只能吸收紫外光（仅占太阳光的4%左右）。
* **g-C3N4 (类石墨相氮化碳)**：作为一种非金属的二维层状材料，其带隙较窄（约 2.7 eV），天生具备良好的可见光响应。近十年来，研究者们密集地将 g-C3N4 与 TiO2 或其他纳米颗粒复合，用以弥补传统氧化物光吸收范围窄的硬伤。

### 2.2 核心改性策略：异质结（Heterojunction）的绝对统治
图谱中 `heterojunction` 和 `charge separation` 呈现出极高频的共现。这反映出当前的科学界共识：依靠单一材料很难实现工业级的催化效率。
通过构建**异质结**（即在两种不同的半导体接触面形成内建电场），能够驱动光生电子（Electrons）和空穴（ there Holes）分别向不同的方向迁移。这种空间上的**电荷分离**机制，成倍地延长了载流子的寿命，是提升整体催化量子效率的核心法宝。

### 2.3 应用场景：双轨并行的发展格局
热点词汇牢牢锁定了两个方向：
* **环境修复 (`degradation`)**：以降解抗生素、染料等顽固性水体污染物为主，是技术走向成熟的立足之本。
* **新能源转化 (`hydrogen production`)**：光催化水分解制氢（以及近年来火热的 CO2 还原转化）。该方向的关键词节点正在快速膨胀，代表了在“碳中和”国际战略背景下，该领域最具想象力和高影响力的终极应用。
